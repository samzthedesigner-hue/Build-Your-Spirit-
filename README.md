# Build-Your-Spirit
Offline daily confession app. Pure Android SDK.

## Music
Upload two MP3s to `app/src/main/res/raw/`:
- `worship_prayer.mp3`
- `worship_instrumental.mp3`

## Build
Push to `main`. GitHub Actions builds and releases `v1.0.<run_number>` automatically.

## Download
Vercel page → latest GitHub Release.
